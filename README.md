# natal-calc-engine

Открытый (AGPL-3.0) сервис астрологических расчётов: натальная карта, синастрия,
транзиты, SVG-колесо. Построен на [kerykeion](https://github.com/g-battaglia/kerykeion) /
Swiss Ephemeris — отсюда лицензия AGPL-3.0 (см. `LICENSE`).

Сервис детерминирован и не содержит бизнес-логики: не знает о пользователях,
тарифах и квотах. Вход — данные рождения, выход — структура карты (JSON) + SVG.

## API (внутренний HTTP)

| Эндпоинт | Назначение |
|---|---|
| `POST /natal` | натальная карта: позиции, дома, аспекты, SVG-колесо; поддержка `time_unknown` |
| `POST /synastry` | межкарточные аспекты двух карт |
| `POST /transits` | транзиты к наталу на дату |
| `GET /places?q=` | геокодинг по локальному справочнику GeoNames (автокомплит) |
| `GET /health` | статус |

Таймзона определяется по координатам и **дате рождения**: `timezonefinder` → IANA-зона →
историческая tzdata (корректно для декретного/летнего времени СССР).

# natal-calc-engine

Открытый (AGPL-3.0) сервис астрологических расчётов: натальная карта, синастрия,
транзиты, SVG-колесо, офлайн-геокодинг. Построен на
[kerykeion](https://github.com/g-battaglia/kerykeion) / Swiss Ephemeris — отсюда
лицензия AGPL-3.0 (см. `LICENSE`).

Сервис детерминирован и не содержит бизнес-логики: не знает о пользователях,
тарифах и квотах, не хранит состояние, не ходит во внешние API.
Вход — данные рождения, выход — структура карты (JSON) + SVG.

## API (внутренний HTTP, порт 8100)

| Эндпоинт | Назначение |
|---|---|
| `POST /natal` | натальная карта: позиции, дома, аспекты, распределение стихий/качеств, SVG-колесо |
| `POST /synastry` | межкарточные аспекты двух карт + оценка совместимости (0–44) + SVG |
| `POST /transits` | транзиты к наталу на заданный момент (`at_utc` — обязателен, сервис не знает «сейчас») |
| `GET /places?q=` | геокодинг по локальному справочнику GeoNames (автокомплит, кириллица/латиница, ё≈е) |
| `GET /health` | статус + наличие справочника |

Особенности:

- **`time_unknown: true`** — расчёт от полудня; дома, ASC/MC и зависящие от них
  аспекты вырезаются из JSON-ответа. Ограничение: на SVG-колесе куспиды домов
  пока рисуются (от полудня) — вызывающая сторона обязана показывать пометку
  о недостоверности домов.
- **Историческая таймзона**: если `tz` не передан, IANA-зона определяется по
  координатам (timezonefinder), смещение — по **дате рождения** из tzdata
  (декретное/летнее время СССР обрабатывается корректно, есть тесты).
- SVG: темы `light` / `dark` / `classic`, язык подписей RU/EN, режим
  «только колесо» или полная карта (с таблицей позиций и сеткой аспектов).
  Примеры — в `examples/`.

## Запуск

```bash
pip install .                       # или: docker build -t natal-calc-engine .
python scripts/load_geonames.py     # весь мир → data/geonames.sqlite (~97 МБ)
uvicorn app.main:app --port 8100
```

Справочник **вшит в образ** (стадия `geonames` в Dockerfile) — на сервере
собирать ничего не нужно, он приезжает вместе с деплоем движка.
Локально скрипт нужен только для отладки поиска.

По умолчанию: полные дампы стран СНГ (с деревнями) + cities500 на весь мир + русские названия из alternateNamesV2. Сузить: `--countries RU --no-world`. Без справочника сервис
работает, но `/places` отвечает 503 (координаты можно передавать напрямую).
